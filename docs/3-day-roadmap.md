# 3-Day Development Roadmap

## Day 1: Foundation & Design
- Finalize architecture, DB schema, and API contracts.
- Set up Supabase and push initial migrations.
- Establish Github repo and basic skeletons (Frontend, Backend, AI).
- **Goal:** Clear plan, infrastructure ready, sample data structure defined.

## Day 2: The Vertical Slice
- Build one complete end-to-end flow for ONE PROJECT.
- AI module generates score -> saved to Supabase -> served by FastAPI -> rendered on Frontend Investigation screen.
- **Goal:** One fully traceable project with explanations working on UI.

## Day 3: Integration & Polish
- Expand to multiple projects.
- Build the Overview Dashboard and Analytics screens.
- Polish UI/UX, responsive fixes.
- Feature freeze and practice demo flow.
- **Goal:** Stable, convincing prototype ready for pitch.
