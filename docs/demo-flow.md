# Demo Flow (2-3 Minutes)

**Core Message:** "The system does not declare fraud. It identifies unusual patterns and tells investigators where they should look first."

**Step 1:** Open Dashboard. Show macro stats (12,482 projects, 347 high-risk).
**Step 2:** Say: "The problem is not simply the amount of data. The problem is knowing where investigators should look first."
**Step 3:** Filter to High-Risk Projects.
**Step 4:** Select Project #23871.
**Step 5:** Show Risk Score (87/100).
**Step 6:** Show the "Risk Fingerprint" (Cost, Progress, Delay, Similarity signals).
**Step 7:** Click "Why was this flagged?"
**Step 8:** Read the explainability outputs: "Cost is 32% above comparable projects. 76% funds utilized vs 39% physical progress."
**Step 9:** Point to the Recommendation: "Priority field verification."
**Step 10:** Conclude: The system provides AI-driven prioritization, not final judgment.
