# Minimum Viable Product (MVP)

The MVP is optimized for "Investigation prioritization and decision support."

## Screen 1: National / District Overview
- Summary metrics (Total projects, high risk, delay risk).
- Risk distribution or district heatmap.
- Filterable table of high-risk projects.

## Screen 2: Project Investigation (The Core)
- Detailed view of a single project.
- **Risk Fingerprint**: Visual breakdown of the unified risk score into individual components (Cost, Progress, Delay, Similarity, Payment).
- **Explainability**: Plain-english reasons for why a project was flagged (e.g., "Cost is 32% above comparable projects").
- **Peer Comparison**: Chart showing this project vs peer group median.
- **Recommendation**: Advisory action (e.g., "Priority field verification").

## Screen 3: Analytics / Comparison
- Macro-level charts showing cost distributions, risk trends across categories or districts.

## Out of Scope for MVP
- User authentication / Enterprise RBAC
- Real-time data streaming
- Blockchain
- Mobile App
