# Team Responsibilities

- **Member 1 (Frontend + Dashboard):** Build the main dashboard, project tables, and analytics overviews.
- **Member 2 (Frontend + UI/UX):** Design system, visual polish, and the core Project Investigation explainability screen.
- **Member 3 (Research + Design Support):** Domain research, gap analysis, ensuring MVP matches workflow, pitch deck preparation.
- **Member 4 (Backend + Supabase):** DB schema design, data ingestion, data pipelines.
- **Member 5 (AI/ML):** Feature engineering, anomaly scoring models, similarity detection, text generation for explanations.
- **Team Lead (Architecture + Integration):** Overall technical direction, FastAPI setup, API endpoints, ensuring vertical slice works, resolving blockers.
